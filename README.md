# Parameter space exploration of DiHiggs production enhancement with new scalars HL-LHC
This repository contains the code and data needed to reproduce arXiv:XXXX.XXXX

Download everything (uncompress some files in DATA) and run the python codes.

Study of the diHiggs production at the HL-LHC with the inclusion of new colored particles, focusing on the $b\bar{b}\gamma\gamma$ channel. ML tools are implemented to explore the entire parameter space and provide prospects of detection and evidence regions were the effects of new physics could be significant.
